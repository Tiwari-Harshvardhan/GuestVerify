# Hackathon Submission Summary

## Project
GuestVerify is a secure, demo-ready delivery verification assistant for the front door. It compares a visitor’s claim against known delivery expectations and prevents any action until it has a homeowner approval decision.

## Why it matters
People often rely on verbal claims at the door. GuestVerify reduces the risk of acting on an unverified claim by giving the user a structured review loop and clear evidence trail.

## Demo value
The application is easy to run locally and shows a believable real-world flow: event ingestion, claim extraction, matching against expected deliveries, evidence review, approval enforcement, and audit recording.

## Key artifacts
- Frontend dashboard and simulator
- Backend verification engine
- API and integration tests
- Environment fallback and audit trail
- Docker configuration for local deployment
